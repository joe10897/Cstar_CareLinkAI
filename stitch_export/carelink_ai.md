# CareLink AI —— 最新頁面路由結構與設計規格清單 (Production Architecture & Route Map)

> **版本**：v2.4 (Haptic & Micro-interaction Enhanced)  
> **設計系統**：Warm Clinical Paper (`#0F766E` 醫療青綠 / `#F8F7F4` 溫潤米白紙感)  
> **平台支援**：Web App (Mobile-first PWA / iOS & Android WebView) + LINE LIFF  
> **觸控與微動效規格**：全站 `active:scale-95 transition-transform duration-150` 物理微縮回彈 + Web Audio API 原生無依賴合成微音 + Web Vibration API 原生 Haptic 回饋。

## 1. 全域路由與導向總覽 (Global Routing Architecture)

```
/ (Root / Entry)
├── /login ─── 登入與身分分流 (LINE 快速授權 / Google OAuth / 獸醫院合作通道)
│
├── /app/* ─── 飼主端主要容器 (固定底部 5 大 Tab 導航列，高度 64px)
│   ├── /app/daily ─────── [Tab 1] 日常打卡與快速記錄 (Haptic 觸感音效版 / 水流動效 / 布里斯托對照)
│   ├── /app/chat ──────── [Tab 2] AI 智慧問診室 (三級緊急度分流 / 歷史血檢與 FGS 掛載)
│   ├── /app/trends ────── [Tab 3] 跨院數據追蹤 (紙本血檢單 OCR 掃描 / 飲水與 CREA 疊圖折線)
│   ├── /app/sitter ────── [Tab 4] 到府保姆實況與交接包 (一鍵授權交接卡 / SOP 現場即時回報)
│   └── /app/profile ───── [Tab 5] 毛孩檔案與健康管理中心 (多寵切換 / 0分基準照 / 醫院合作網絡)
│
├── /app/fgs-scanner ───── 全螢幕專注檢測室 (AI 貓臉 48 點 FGS 掃描室 / 雙主題標註 / 觸感音效)
│
└── /sitter/* ──────────── 保姆端專屬工作台 (切換自飼主端或保姆登入)
    └── /sitter/portal ─── 保姆端接案與執勤工作台 (Sitter Portal / SOP 護理四步驟展開 / 派案管理)
```

## 2. 核心最新頁面詳細規格 (Latest Screen Specs)

### 頁面 1：登入與身分分流頁 (Auth & Onboarding)
* **路由路徑**：`/login`
* **目前最新畫面**：`登入與身分分流 (LINE & Gmail)`
* **版面架構**：`mobile_blank`（全螢幕乾淨佈局，無導覽列）
* **核心模組與設計特點**：
  * **Brand Hero**：CareLink AI 標誌與「全齡犬貓健康 ✕ AI 醫療初篩 ✕ 專業到府保姆」副標。
  * **雙主軸 OAuth 登入**：
    * `LINE 快速登入`（綠色主 CTA，支援 LINE LIFF 內免授權一鍵靜態綁定）。
    * `Google 帳號繼續`（白色高質感卡片）。
  * **次級登入與合作通道**：手機簡訊驗證碼登入、獸醫院夥伴特約通訊入口。
  * **法律與權益精簡化**：移除大篇幅法律聲明，改為底線小字微型按鈕「使用者條款」與「隱私權保護政策」，保障視覺極致清爽。

### 頁面 2：[Tab 1] 日常打卡與快速記錄 (Daily Care & Haptic Quick Log)
* **路由路徑**：`/app/daily`
* **目前最新畫面**：`日常打卡與快速記錄 (Haptic 觸感音效版)`
* **版面架構**：`mobile_tab`（頂部 Pet Context Header + 底部 5 大 Tab 導航列）
* **核心模組與設計特點**：
  * **頂部毛孩切換器**：展示頭像、名字（如「咪寶」）、品種、年齡（8y 2m）與健康標籤（`IRIS 腎病第 2 期`）。
  * **Haptic 音效控制膠囊**：`🔔 觸覺與提示音：開啟中`，點擊即時發出 1300Hz 溫潤臨床音效與 8ms 輕微微震。
  * **AI 貓臉 FGS 疼痛快篩入口卡片**：醒目深青綠色漸層卡片，標註上次快篩 `0/10 (無疼痛徵兆)`，提供相機圖標與「立即評估 →」引導。
  * **核心日常打卡 Bento 區塊**：
    * **飲水進度**：具備液體水流充填波紋動效 (`animate-water-wave`)，`+50ml` 快捷按鈕配備 `active:scale-95` 彈性跳動反饋。
    * **食慾狀態**：`正常 / 減半 / 拒食` 三段切換膠囊。
  * **可折疊深入照護面板 (Accordion)**：
    * **排泄健康**：內建布里斯托大便 7 級圖示對照（🌰 乾硬、🥖 理想、🍦 軟便、🌊 水便）與尿塊大小標記。
    * **體重與皮下輸液**：每日輸液 `100ml` 標記、降血壓藥物服用打卡。
    * **異常備註**：供飼主與保姆交接時備忘之折疊文字區。

### 頁面 3：全螢幕 AI 貓臉 48 點 FGS 掃描室 (Feline Grimace Scale Scanner)
* **路由路徑**：`/app/fgs-scanner`
* **目前最新畫面**：`AI 貓臉 48 點 FGS 掃描室 (Haptic 觸感音效版)`
* **版面架構**：`mobile_stack`（沉浸式全螢幕，頂部返回鍵，無底部導覽列）
* **核心模組與設計特點**：
  * **相機與 48 點五官分區畫布**：
    * 支援「白底三色」與「深色五色分區」雙主題切換。
    * 48 個關鍵點即時座標網格（雙耳 01-10、眼眶 11-26、鼻樑 27-34、口唇 35-38、臉頰 39-48）。
    * 雙眼 EAR 縱橫比計算指標（例如：`EAR 0.294 Slight Tightening`）。
  * **臨床 FGS 評估結果抽屜 (Bottom Sheet)**：
    * 顯示總分 `FGS 1/10 (綠色安全觀察)`，置信度高達 `98.4%`。
    * AU 幾何解構細項（耳位向前、眼眶輕微微瞇、鬍鬚墊自然舒展）。
  * **跳轉 AI 問診高對比引導卡**：
    * 標註已自動打包「眼眶微瞇 / 飲水紀錄 / CREA 指標」3 項特徵。
    * 點擊主 CTA **「帶入 AI 智慧問診深入分析 →」** 觸發雙音階確認音效與雙重觸控微震。

## 3. 設計規範與 Token 對齊表 (Design Tokens)

| Token 變數名稱 | Hex / 數值 | 語意與設計規範用途 |
| :--- | :--- | :--- |
| `--color-bg-canvas` | `#F8F7F4` | 溫暖米白畫布底色（Warm Clinical Paper），降低醫療焦慮 |
| `--color-surface-card` | `#FFFFFF` | 主卡片純白背景，對比鮮明 |
| `--color-surface-dark` | `#1E242B` | AI 貓臉 48 點相機檢測室專用暗色背景 |
| `--color-brand-primary`| `#0F766E` | 沉穩醫療青綠色（主 CTA、選中 Tab 高亮、完成圖示） |
| `--color-status-safe`  | `#15803D` | FGS 0-1 分安全 / 血檢正常值 / 打卡完成 |
| `--color-status-warn`  | `#D97706` | FGS 2-3 分微疼邊緣值 / 待觀察 |
| `--color-status-danger`| `#DC2626` | FGS $\ge$ 4 分中重度疼痛 / 急診預警紅燈 |
| `--font-sans`          | `Plus Jakarta Sans`, `Noto Sans TC` | 全站中文與英文標題、內文 |
| `--font-mono`          | `JetBrains Mono`, `monospace` | FGS 分數、血檢數值、48 點座標、費用與時間戳記 |

| `--audio-feedback`     | `Web Audio API` (1200~1400Hz) | 零依賴溫潤臨床點擊微音（輕微水滴音） |
